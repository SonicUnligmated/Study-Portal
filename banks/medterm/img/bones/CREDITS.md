# Image credits: Lecture 11 Musculoskeletal bone images

Files are renamed by question id (bone-mt11077.png …) so the file name never gives the answer away. In the quiz, the caption under each picture links to the license; the source pages are listed here.

All images come from Wikimedia Commons. 20 of them are from the BodyParts3D / Anatomography series (Database Center for Life Science, DBCLS), licensed **CC BY-SA 2.1 Japan** (https://creativecommons.org/licenses/by-sa/2.1/jp/deed.en). The patella image is by Patrick J. Lynch, licensed **CC BY 2.5** (https://creativecommons.org/licenses/by/2.5/).

Changes made to every image: cropped around the highlighted bone, resized to at most 800 px, and saved as an optimised PNG. None of the source images contain text. Because these are adapted from CC BY-SA images, the adapted versions are shared under the same license (CC BY-SA 2.1 JP).
